## (a) 四范式碰撞图是否成立

**判定：pass**

**意见：**

1. **P1 区间算术证书**：以“外向舍入包络 + 认证不可行性”作为非存在性证据，和联邦级名体系中的“证书即名”同构成立。关键在于 `|marg|≤1.55e-11`、`cost宽1.32e-13` 属于**求值层非存在性层**的界，不应被解释为 LP 最优性证明本身。若碰撞图中把 P1 标为“存在性/非存在性证书”而非“数值解”，同构准确。

2. **P2 SAT 证明证书**：DRAT/LRAT 类证书与 schema 机检的同构成立，但必须区分：
   - 证书生成器可不可信；
   - 检查器是否被独立验证；
   - 证书语义是否覆盖“恶意假证书”情形。  
   这与 (c) 的 FM-015 直接耦合。碰撞图若把 P2 仅画成“证明可机检”，同构偏弱；若画成“证明可机检 ∧ 检查器 TCB 可审计”，则成立。

3. **P3 形式化证明助手**：与 fp 互锚、退火路径的同构基本成立，但需避免把“内核小”误当成“整体可信”。真正的同构点是：**小内核 + 大库 + 可审计公理/扩展机制**，而非“助手整体形式化”。

4. **P4 PINN 失败模式**：作为“残差小但解错/不可认证”的范式，与区间证书、SAT 证书、形式化证明形成有效碰撞。其同构判定应落在“**弱监督/软约束不能替代证书**”，而非“PINN 不可用”。若报告如此表述，成立。

5. **联邦级名体系 / schema 机检 / fp 互锚 / 退火路径**：四者同构判定总体准确，但需注明：
   - 名体系解决的是**身份与寻址**；
   - schema 机检解决的是**结构合规**；
   - fp 互锚解决的是**跨层引用完整性**；
   - 退火路径解决的是**从候选到正式授予的动力学**。  
   四者不是同一层，而是**同一联邦信任栈的不同层**。若碰撞图把它们画成同层并列，则同构过强；若画成分层耦合，则 pass。

**结论：** 四范式碰撞图成立，但需把“同构”限定为**分层同构 / 证书-检查器-审计三角同构**，而非平面等价。

## (b) M4/M5/M6 是否够格入册为洞见级镜像律

**判定：pass**

**意见：**

- **M4 延拓律（curriculum ≡ 退火 ≡ 同伦）**：够格。三者共享“连续变形保持可追踪性”的结构。入册条件：必须补**反例边界**——当离散跃迁/相变导致拓扑改变时，延拓律失效或需分段。若镜像律允许“域限”标注，则 pass。

- **M5 TCB 最小化律（求解器不可信 + 小型检查器 + 检查器须被检查）**：够格，且是当前最硬的一条。它与 FM-015 形成直接互证。入册条件：三条必须同时成立，不能只取前两条。若只写“求解器不可信 + 小检查器”，会退化为口号；加上“检查器须被检查”才成为律。

- **M6 审计锚律（内容寻址为第三方复核前置）**：够格，但应写成“**内容寻址是第三方复核的必要非充分前置**”。否则会被误解为“哈希即审计”。内容寻址只保证**同一性**，不保证**正确性**；正确性仍需检查器与证书语义。

**结论：** M4/M5/M6 均够格入册为洞见级镜像律，但每条需附**失效条件 / 域限**，否则会从“律”退化为“隐喻”。

## (c) FM-015 候选是否入 FM-LIB

**判定：pass（conditional / case-level）**

**意见：**

- **drat-trim 实案：检查器接受恶意假证书**，是 FM-015 的强实证。它说明：
  - 证书格式合规 ≠ 证书语义可靠；
  - 检查器实现漏洞可导致“机检通过但证明无效”；
  - 因此 TCB 必须包含检查器自身。
- 入 FM-LIB 的条件：
  1. 明确标注为 **case-level failure mode**，而非普遍性结论；
  2. 标注受影响检查器版本/配置/输入类别；
  3. 与 M5 绑定：FM-015 是 M5 第三支“检查器须被检查”的实证；
  4. 给出缓解：检查器形式化验证、差分检查、多检查器交叉、证书语义审计。
- 不建议因为该实案就宣布“SAT 证书不可信”；应宣布“**未经验证的检查器不可信**”。

**结论：** 入 FM-LIB，但标 conditional，并要求与 M5 互锚。

## (d) 元问题 v2 重构与 META-PIPE-01 是否批准为联邦元结构

**判定：pass（附修正条款）**

**意见：**

- **元问题 v2 重构**：  
  “任意候选对象信任级的机检化 / 可申诉 / 域限 / 跨范式制度化授予维持降级撤销”作为元结构，方向正确。它把信任从“静态等级”变成“可操作生命周期”。批准条件：
  1. **机检化**必须区分“可机检部分”与“需人类判断部分”；
  2. **可申诉**必须包含反事实与证据继承；
  3. **域限**必须显式，禁止跨域自动升级；
  4. **降级/撤销**必须触发下游依赖重检。

- **META-PIPE-01**：  
  “候选 → 框架伴生 → 双轮 → 域限正式 → 镜像锚定 → 证书化 → 对抗复核”流程合理，批准为联邦元结构。但需补：
  1. **撤销后证据继承/反事实归档**：被撤销对象的历史证据不能直接删除，应标记为“已撤销但可审计”；
  2. **对抗复核的独立性**：复核者不能与被复核对象共享同一 TCB；
  3. **证书化与镜像锚定的顺序**：若镜像锚定先于证书化，需说明锚定的是“候选身份”还是“已证内容”。

**结论：** 批准，但必须加入撤销继承、复核独立、锚定语义三条修正。

## (e) F-X1 区间证书实验效力是否认可

**判定：pass**

**意见：**

- `|marg|≤1.55e-11`、`cost宽1.32e-13`、含 f64/f80 双包含、亚 LP 松弛由认证不可行性解释，6/6 PASS。这些指标支持**求值层非存在性结论**，即：在给定区间包络与认证不可行性下，未发现可行解/未发现更优解。
- 效力边界必须写清：
  1. 这是**求值层非存在性层**，不是 LP 最优性层；
  2. 区间包络依赖外向舍入实现，需说明硬件/编译器/库版本；
  3. f64/f80 双包含是加分项，但不能替代对区间库本身的审计；
  4. 6/6 PASS 是实验内结论，外推需域限。
- 若报告只声明“认证不可行性解释亚 LP 松弛”，而不声明“不证明 LP 最优性”，则效力认可。

**结论：** 认可，但需在证书中显式标注“求值层非存在性层，不构成 LP 最优性证明”。
