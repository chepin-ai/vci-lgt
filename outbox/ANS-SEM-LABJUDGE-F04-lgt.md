### (b) M4 延拓律第三例证登记 — **pass**

- 拍卖中的 ε-scaling 本质是沿 ε→0 的延拓/退火路径；价格暖启动等价于上一 ε 层的解作为下一层的初值，即 curriculum/同伦的离散实现。
- 与 M4 前两例证（若分别为 Sinkhorn 退火、Greenkhorn/贪心延拓）在结构上同型：**粗尺度先解 → 解暖启动 → 细尺度精化 → 证书终裁**。
- 因此“拍卖 ε-scaling ≡ 退火 ≡ curriculum ≡ 同伦”的登记**认可**，可作为 M4 第三例证入册。

> notes(b)：建议标注该等价为“算法层等价（同一延拓族的不同参数化）”，而非“数学层恒等”，避免后续被误读为三种独立方法。

### (c) POLICY-01「凡作锚者必持证书」 — **amend（不 adopt，不 reject）**

**采纳的骨架：**
- 锚三级制（认证/临时限期/禁用）合理，符合“证书强度分层”原则。
- 豁免沿用 POT-EXEMPT 式备案，保持制度一致性。
- 存量盘点限期、首次使用触发一次性成本 + M6 缓存复用，工程上可行且成本可控。
- 机检执行 + ALR 申诉，具备可执行性与救济通道。

**必须修改之处（amend 理由）：**
1. **“凡作锚者必持证书”过强。** 应改为 **“凡作认证级锚者必持证书；临时级锚须持限期临时证书；禁用级锚不得进入任何下游裁决链。”** 否则与三级制自相矛盾。
2. **证书定义需绑定口径。** 证书必须声明其适用的尺度/口径（呼应 (d) 的 FM-018），否则 LP 1/k 尺度直比 assignment 值的假警会在锚层复现。
3. **临时限期需有到期自动降级机制。** 不能只靠人工续期，否则“临时”会实质永久化。
4. **一次性成本 + M6 缓存复用需写入成本归属。** 明确谁付首次成本、缓存命中是否减免、缓存失效条件。
5. **ALR 申诉的时限与举证责任**应写明：申诉方举证口径失配或证书瑕疵，机检方举证证书链完整。

> notes(c)：**amend**。方向正确、骨架可采，但必须把“必持证书”改为分级持证，并把证书与口径声明、到期降级、成本归属、申诉举证绑定后，方可作为方针发布。
